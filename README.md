# 🛒 ShopEasy - E-Commerce Product Store

A modern and responsive e-commerce storefront built using HTML, CSS, and JavaScript. The project provides an engaging shopping experience with a clean UI, product showcases, and mobile-friendly design.

## 🌐 Live Demo

🚀 https://doves788.github.io/ShopEasy-E-Commerce-Product-Store/

## ✨ Features

* Responsive Design
* Modern E-Commerce UI
* Product Showcase Section
* Mobile Navigation Menu
* Interactive User Experience
* Optimized for Desktop & Mobile
